Self-hosted font assets for Expenzo

Current website: Syne display type and Manrope body type. See Syne-README.txt
and Syne-OFL.txt for Syne's source and license. Space Grotesk below is retained
as an unused asset from the previous website design.

Space Grotesk, variable normal weights 400-700, Latin WOFF2:
https://fonts.gstatic.com/s/spacegrotesk/v22/V8mDoQDjQSkFtoMM3T6r8E7mPbF4Cw.woff2
Project: https://github.com/floriankarsten/space-grotesk

Manrope, variable normal weights 400-800, Latin WOFF2:
https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2
Project: https://github.com/googlefonts/manrope

Both are distributed under the SIL Open Font License 1.1 (see OFL.txt).
Font files are served locally. The website makes no runtime request to
Google Fonts or another font service. Characters outside the Latin
subsets use the system-font fallback.
